## Learned User Preferences

- Keep the interface free of shadows. Motion should feel slow, smooth, and heavy—long easing curves and opacity/filter interpolation only. No bounce, springy overshoot, scale-in, or slide-in entrances.
- Treat the site background as solid white only; avoid extra fill colors on panels or cells unless placeholder media explicitly keeps its fill.
- `SiteBrandStrip` is the fixed transparent top band on home, info, work, and project pages: Daniel Derro links home (left); a Menu trigger (right) opens `MobileMenuOverlay` — full-viewport primary-red overlay with stacked `text-heading` nav links (Home, Info, Work, Exhibitions, Radio), two-digit accent numbers, and black "– Coming Soon" body text on placeholder routes. Active nav links default black and invert to white on hover (fast transition); Coming Soon rows have no hover. Brand name links fade to 40% opacity on hover. Home no longer applies the header blend overlay (`SiteChrome` renders plain `SiteBrandStrip`).
- Site-wide page navigation lives in `MobileMenuOverlay` only — there is no fixed bottom nav row. `SitePageFooter` (via `InfoColumns` `siteFooter`) is the shared in-flow footer on home, info, and work; `SiteFooter` renders only on project detail pages (title, tags, slide counter) pinned to the viewport bottom with transparent background and enough scroll padding to clear it.
- For local checks, run the dev server on port 3000 via `npm run dev` (routes through `scripts/dev.sh` which kills stale listeners before launching Turbopack). Use `npm run dev:clean` to wipe `.next` first when manifest/cache errors appear.
- UI stack is Next.js with Tailwind, Framer Motion for animation, and Lenis for smooth scrolling; Sanity CMS at `/studio` is used for client-managed portfolio content. Motion tokens live in `src/lib/motion.ts`; the `.hover-smooth` utility class in `globals.css` handles CSS-driven hover transitions.
- Keep all site typography editable in one `globals.css` Typography block — `.text-micro`, `.text-micro-tight`, `.text-caption`, `.text-body`, `.text-heading`, and `.text-semantic-title` (Times New Roman Bold, 16px) ordered smallest→largest with explicit font values; do not scatter typography rules across components. Semantic section titles use `.text-semantic-title` site-wide with 0px gap to the body copy directly below.
- On small screens, use uniform padding around the layout via `--spacing-margin` (12px at all breakpoints).
- Home hero is `HomeHero.tsx` (not `InfoColumns`): portrait, About, Clients, and six logos in a center-aligned stack within `page-grid` columns 3–4 (`col-span-2 col-start-3` on md/lg). Portrait uses `SnugFillImage` (`w-full h-auto object-contain`). `gap-3` (12px) between the four main blocks; hero logos are 40px tall, 12px apart, 0.5px black stroke (`public/images/hero/`). No full-viewport blurred background hero.
- On the home page, present the Sanity-fed gallery as a continuous six-column image grid without per-project title rows; show at most 30 images with each row filled; align rows to the top with uniform vertical gap between rows; clicking a gallery image navigates to that image's project. When hovering a gallery image, non-hovered images use about 20% opacity and grayscale.
- On the work page, each project is one generously spaced row on the six-column `page-grid` with empty offset columns 1–2 on lg: numbered index (001…), title/category metadata, and a horizontal thumbnail strip; the whole row links to the project. Black background; `SitePageFooter onDark` at the bottom. No cursor-following hover preview.
- `SitePageFooter` footer grid is top-aligned: column 1–2 hold four side-by-side footer logos (40px height, 0.5px black stroke, no gap); Contact in column 3; Follow in column 4. Footer semantic titles at 20% opacity; body copy black (white on dark work footer). Local static logo images use native `<img>` with `object-contain` to avoid Next.js Image crop/fill.
- Target responsive column counts: two columns below 768px, four columns from 768px to 1023px, six columns from 1024px up (aligned with `.page-grid` breakpoints).

## Learned Workspace Facts

- The app uses Next.js 15 (App Router), React 19, and Tailwind CSS v4 with `@tailwindcss/postcss`.
- Layout uses responsive `.page-grid` in `globals.css`: two columns by default, four from `min-width: 768px`, six from `min-width: 1024px`; `--spacing-margin` is 12px at all breakpoints; `--spacing-gutter` scales by breakpoint. The home gallery uses row spacing tied to `--spacing-gutter` so vertical gaps match horizontal column gutters (avoid a global `.page-grid` `row-gap: 0` rule that overrides intended row gaps).
- Earlier microsite code is archived under `src/archive/` rather than mixed into the current site surface. `tsconfig.json` excludes `src/archive` so archived code is not type-checked; `npm run build` can still fail if archived files import packages that are no longer dependencies.
- Global styles strip box shadows site-wide. Framer Motion handles animation (page transitions via `src/app/template.tsx`, hover/scroll via motion components). Lenis smooth scroll is initialized in `src/components/SmoothScroll.tsx` (lerp 0.07 for heavy feel). Both providers skip `/studio` routes.
- Stale or mixed `.next` output (for example after `next build` then `next dev`) can cause local Internal Server Errors or missing chunk errors; `npm run dev:clean` handles this automatically.
- Never leave large directories (e.g. `node_modules_old`) in the project root — they cause webpack/Turbopack file-watcher exhaustion and hang page compilation indefinitely. `.gitignore` now blocks `node_modules_old`.
- Embedded Sanity CMS powers portfolio projects and media; Studio is at `/studio`. Use versions aligned with Next.js 15 (for example `sanity@4` with `next-sanity@11`). Until video playback exists, gallery `videoAsset` entries should use thumbnails only as on-page stills. Public contact email shown in the site UI is `info@ns-sr.org`. Server routes use `sanityFetchOrDefault` in `src/sanity/lib/fetch-safe.ts` so failed Sanity fetches fall back to empty data or `notFound` instead of throwing 500s.
- The site has three page routes beyond home: `/info` (white background; About copy stacks in column 3 with semantic titles), `/work` (black `WorkProjectGrid` editorial list with `SitePageFooter onDark`), and `/work/[slug]` (vertical scroll with viewport-snapped 100dvh slides, 200px top/bottom image padding, fixed `SiteFooter`; no slideshow cursor). Work routes use `src/app/work/layout.tsx` with `data-work-surface`; `globals.css` sets `html`/`body` black when that marker is present so rubber-band overscroll does not flash the default white canvas.
- All main surfaces share `SiteBrandStrip` for the top band (Daniel Derro + Menu). Client breakpoints use `useMediaQuery` in `src/lib/use-media-query.ts`. Project detail desktop split footer layout uses `MEDIA_DESKTOP_FINE_POINTER` in `src/lib/media-queries.ts` (`(min-width: 1024px) and (pointer: fine)`) so wide viewports with touch keep touch-first layout.
- Site typography tokens in `globals.css` (Helvetica Neue via `--font-sans`): `.text-micro` (8px), `.text-micro-tight` (8px tighter lh), `.text-caption` (11px), `.text-body` (16px/600), `.text-heading` (60px/600 for menu nav links), `.text-semantic-title` (Times New Roman Bold 16px for section headings).
- Shared About/Clients copy and hero logo assets are centralized in `src/lib/site-content.ts`; `SnugFillImage` width-fills parent columns without cropping (`src/components/SnugFillImage.tsx`).
- `src/middleware.ts` injects a 2u4u.studio-style HTML credit comment immediately after the opening `<html>` tag on HTML navigations; the matcher skips `/studio`, static assets, and API routes.
