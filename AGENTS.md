## Learned User Preferences

- Keep the interface free of shadows. Motion should feel slow, smooth, and heavy—long easing curves and opacity/filter interpolation only. No bounce, springy overshoot, scale-in, or slide-in entrances. Prefer a minimal site scrollbar (thin, low-contrast light thumb on the black canvas).
- Keep page canvases flat and black site-wide (`html`/`body` use `--color-black`). Avoid extra panel/cell fills unless placeholder media explicitly keeps its fill.
- `SiteBrandStrip` is the fixed transparent top band on home, info, work, gallery, radio, and project pages: Daniel Derro is the only Home link (left, `.text-small`). Navigation splits by breakpoint. Desktop (≥768px) uses a traditional inline nav (`SiteNavLinks`) on the page `.layout-grid` — Work/Gallery/Info/Radio in that order, side by side with a 12px gap, sitting in the fourth content column (track 4 on the 4-col grid, track 8 on the 8-col grid) aligned to that column’s right edge (not the 300px compact measure). Mobile (<768px) hides that nav and uses a text-only `MobileMenuTrigger` pinned to the top-right: the current page name, fading to Menu when open — no plus/minus, no 140px panel, no frost, no backdrop blur. Opening it drops an accordion of `.text-heading` links that pushes page content down (`--site-mobile-nav-shift`) instead of overlaying it. The header bar is `.layout-grid` (`site-brand-strip-bar`). Brand name links fade to 40% opacity on hover. Do not put Venice/Nineteen Eighty Six in the header. On home, info, and project detail, `SiteChrome` may pass `blendOverlay` so the brand uses exclusion blend (`blend-overlay`) for legibility over media.
- Site-wide page navigation lives in the brand strip only (desktop inline nav, mobile accordion — both from `MobileMenuOverlay.tsx`); there is no fixed bottom nav row and no Home item in the menu. `SitePageFooter` is the shared in-flow footer on info, work, and gallery (home is a locked hero with no in-flow footer; radio has none); `SiteFooter` renders only on project detail pages (title, tags, slide counter) pinned to the viewport bottom with transparent background and enough scroll padding to clear it. Do not show a phone number in the footer; contact on `/info` is email only (`info@ns-sr.org`).
- For local checks, run the dev server on port 3000 via `npm run dev` (routes through `scripts/dev.sh`, which kills stale listeners then launches Turbopack with `--disable-source-maps`). Keep exactly one dev server and one terminal for it — reuse or kill the existing listener instead of opening more. The repo lives on iCloud Desktop; file-provider I/O can stall Next boot and first-page compile until the folder is downloaded locally. Use `npm run dev:clean` to wipe `.next` first when manifest/cache errors appear. If localhost does not match expected UI, confirm the checked-out branch — home hero/footer redesign lives on `feature/home-hero-updates`, not necessarily `main`.
- Media quality outranks byte size everywhere, because the site is a visual artist portfolio. Every `next/image` on the site is `quality={90}`, Sanity project slides (the actual artwork) are quality 90 capped at `PROJECT_SLIDE_MAX_WIDTH` 2560px, and the hero video ships as H.264 CRF 18 only. Do not trade fidelity for weight when optimizing: an AV1/WebM variant was measured, was 84% smaller, and was rejected because it flattened the sunset gradient and shadow grain.
- Keep all site typography editable in one `globals.css` Typography block — `.text-caption`, `.text-caption-tight`, `.text-fine`, `.text-small`, `.text-body`, `.text-heading`, and `.text-semantic-title` ordered smallest→largest with explicit font values; do not scatter typography rules across components. `.text-semantic-title` matches body scale and appends a trailing comma via `::after`; semantic section titles sit flush (0px gap) above their body copy. Do not change font sizes while making structural, semantic, performance, or accessibility changes — typography moves only when it is the explicit request.
- All public horizontal content must use one of three rules in `globals.css`: `.layout-grid` (full-width media grid: 2 columns below 768px, 4 from 768–1023px, 8 from 1024px), `.content-compact` (fluid to 300px), or `.content-wide` (fluid to 800px, with optional `.content-wide-grid` internal columns). Keep `--spacing-margin` at 12px. Do not introduce unrelated max-widths or alternate column systems. Column changes made for one surface must not leak into another — work-page column work should leave `/info` untouched.
- Home is a locked full-viewport original video hero (`HomeHero.tsx`, `100dvh`, `overflow: hidden` on html/body) — no project index/list, no gallery, no page-grid overlay, no page scroll, no in-flow footer. The intro video fills the viewport like production (`object-fit: cover`, inset 0 / `100dvh`); the looping muted video (`HERO_VIDEO_SRC` `/videos/dd-intro-hero.mp4`, poster `HERO_POSTER_SRC` `/images/daniel-hero-poster.webp`, both exported from `SiteBackgroundVideo.tsx`) must not show a native Safari play button or controls (`playsInline`, hide `::-webkit-media-controls`). Over it sits one centered `.text-small` statement (`home-hero-center`) locked to the 300px compact width and vertically centered in the viewport: three period-terminated lines (`No School Studios is a visual practice.` / `Founded and operated by Daniel Derro.` / `Based in Venice.`) where only `No School Studios` and `Daniel Derro` are white and the rest is grey `#808080`. The block uses `mix-blend-mode: exclusion` over the video — apply the blend on the wrapper, not the spans, or it will not render.
- The work page follows the Something Special Studios index pattern. A fixed black header (`work-page-header`) sits under `SiteBrandStrip` and stacks a right-aligned `.text-heading` (standing text `Work` at 20px on mobile, crossfades to the hovered project title, no character limit) above a `text-small` filter group (right-aligned on mobile); title and filters stay pinned and do not scroll with the index. Gaps from brand → title → filters → first project use `--work-row-gap` (12px). Each project is a tight row: a full-width flush thumbnail strip (no gaps, no borders) with a caption row beneath it — client, title, category, year — as a single `text-small` line on the 4-col measure from 768px (tags right-aligned and never wrapping; when year is empty they sit on the right edge); below 768px only client and title show, at reduced scale. The 4-column caption measure must land identically in every filter view, Motion and No School included. Every strip is the same height (`--work-thumb-height`); overflow scrolls horizontally with no visible scrollbar, and the scroller breaks out of the 12px page margin (`.work-row-strip` negative inline margins, margin re-applied as padding on `.work-row-strip-inner`) so scrolled thumbnails run to the viewport edges while the resting first/last thumb still aligns with the caption grid — horizontally scrollable content is never boxed in by page padding. Thumbnails keep their intrinsic aspect ratio via CSS `aspect-ratio`. Hovering a row for 150ms dims every other row to 0.18 (opacity only, no grey fill, no cursor-following preview); leaving or scrolling cancels the hold or clears immediately. Disable the dim on mobile. Client falls back to “No School Studio” for No School rows, otherwise “Personal”. The filter group is All, A-Z, Stills, Motion, No School: every view except A-Z lists projects newest-uploaded first (Sanity `_createdAt`, with the undated No School Vimeo catalog trailing in feed order), and A-Z shows everything sorted alphabetically by title. Every filter click must play the same transition on mobile and desktop — never a blink, an instant removal, or an in-place re-sort: the list is keyed by the active filter inside `AnimatePresence`, so the old list fades and blurs out as one block and the new one cascades back in with the standard per-row stagger. Black background; `SitePageFooter onDark` at the bottom.
- `/gallery` is a black stills index on `.layout-grid` (2/4/8): pack enough project stills to fill the viewport (`buildGalleryStills` in `src/lib/gallery-stills.ts`, shuffled once on the server). Tiles keep intrinsic aspect ratio (`object-fit: contain`); gallery-only gap is 80px — do not change site `--spacing-margin` (12px) or `--spacing-gutter` (20px). Desktop hover (150ms hold, none on mobile) dims other tiles to 0.18 and shows a fixed viewport-center `.text-caption` row — client, title, tags — with exclusion blend (title uses literal `#ffffff` so it survives the blend). Tiles link to `/work/[slug]`. `SitePageFooter onDark` at the bottom.
- `SitePageFooter` is a single centered `.text-caption` line in the 300px `.content-compact` rule: `© 2026 NO SCHOOL STUDIOS. ALL RIGHTS RESERVED.` in `#808080`. No links or logos. The gap above it matches `--work-row-gap` (12px); no extra padding below. Page shells are `min-height: 100dvh` flex columns so the footer `margin-top: auto` pins it to the bottom of the viewport when content is short, and to the end of the document when content is long.

## Learned Workspace Facts

- The app uses Next.js 15 (App Router), React 19, and Tailwind CSS v4 with `@tailwindcss/postcss`.
- Hero media is regenerated by `scripts/encode-hero-media.sh <master>` from originals in `assets/masters/` (`dd-intro-master.mp4`, `daniel-hero-master.jpg`) — masters live outside `public/` so they are never deployed. The script emits `/videos/dd-intro-hero.mp4` (H.264 CRF 18) and `/images/daniel-hero-poster.webp`, and uses `sharp` for the WebP because the installed ffmpeg has no `libwebp`. The hero master is only 980x720, so the viewport-filling video is upscaled — that resolution ceiling, not the encode, is the remaining quality limit.
- Earlier microsite code is archived under `src/archive/` rather than mixed into the current site surface. `tsconfig.json` excludes `src/archive` so archived code is not type-checked; `npm run build` can still fail if archived files import packages that are no longer dependencies. Live components have the same exposure — `SimpleVideoPlayer` dynamically imports `@grizzshutsdown/simpleplayer`, which must stay in `dependencies` or Vercel fails the build with a module-not-found error even though local type-checking passes.
- Global styles strip box shadows site-wide and define a minimal scrollbar outside Sanity Studio (`--scrollbar-size` 3px, low-opacity white thumb). `html` sets `overflow-y: scroll` with `overflow-x: hidden` so the root bar's width is always reserved — Safari ignores `scrollbar-gutter` on the viewport, so without it navigating between a scrolling page (work) and a locked one (radio/home) shifts content horizontally. Framer Motion handles animation (page transitions via `src/app/template.tsx`, hover/scroll via motion components); motion tokens live in `src/lib/motion.ts` and the `.hover-smooth` utility class drives CSS hover transitions. Page transitions skip `/studio` routes. Scrolling is native site-wide; only `/work/[slug]` uses CSS scroll-snap on `.project-scroll`.
- Local build and verification gotchas, most of them iCloud artifacts rather than code errors: stale or mixed `.next` output (for example `next build` then `next dev`) causes Internal Server Errors or missing-chunk errors, and iCloud conflict copies (`build 2`, `server 2`, `static 2`, `cache 2`) hang `next build` mid-compile at 0% CPU — `npm run dev:clean` or clearing `.next` fixes both. `next build` can also fail at the very last step with `ENOENT ... rename '.next/export/500.html'` after every page compiled and generated successfully; that is the same transient filesystem race, so clear `.next` and rerun. Never leave large directories (e.g. `node_modules_old`, now blocked by `.gitignore`) in the project root — they exhaust the webpack/Turbopack file watcher and hang compilation indefinitely. `npx eslint src --ext .ts,.tsx` hangs because `--ext` is deprecated under flat config; use `npm run lint` or the build's own lint step. `npm run dev` fails inside a restricted sandbox with `uv_interface_addresses returned Unknown system error 1` and must be run unsandboxed.
- Cursor's browser automation injects a `data-cursor-ref` attribute into the DOM after hydration, so the React hydration-mismatch warning it raises in the Next.js dev overlay is a tooling artifact that never appears in production. Scripted `.focus()` does not trigger `:focus-visible` and the browser tool's synthetic Tab keypress does not move focus, so verify focus styling with CDP `DOM.enable` + `CSS.enable` + `CSS.forcePseudoState` set to `focus-visible` and read the computed styles.
- Embedded Sanity CMS powers portfolio projects and media; Studio is at `/studio`. Use versions aligned with Next.js 15 (for example `sanity@4` with `next-sanity@11`). Public contact email shown in the site UI is `info@ns-sr.org`. Server routes use `sanityFetchOrDefault` in `src/sanity/lib/fetch-safe.ts` so failed Sanity fetches fall back to empty data or `notFound` instead of throwing 500s. Project slides use a blurred LQIP/`sanityImageBlurUrl` placeholder while the full image loads.
- Home is a locked 100dvh video-only `HomeHero` (no `--site-content-offset-top` in-flow). Other main surfaces sit `--work-row-gap` (12px) below the fixed brand strip: `/info` uses the same looping hero video as home (`SiteBackgroundVideo` fixed, dimmed to 80%) under the same full-width `.layout-grid` as `/work` (each block `grid-column: span 2`) with `.text-small` copy — grey `#808080` `.text-caption` section titles, white main content, links in `--color-primary` red; `Daniel Derro` white inside the about paragraph; services sit in one Services column; there is no Studio group; clients split into two isles with a 12px gap; row gap is `calc(var(--work-row-gap) * 2)` and label gaps match `--work-row-gap`; `/work` is a black full-width index of flush thumbnail strips with caption rows; `/gallery` is a black 8-col stills index (see preferences); `/work/[slug]` uses full-width viewport-snapped media where photos stay full-bleed and videos sit on two `.layout-grid` tracks (`.project-slide-video`, `grid-column: span 2` — full content width on the 2-col mobile grid, half on 4-col, the first two tracks on 8-col; No School video pages match), with a fixed `SiteFooter` on the 800px `.content-wide` rule; `/radio` uses the same dimmed looping hero video as `/info`. From 768px the grid has two areas: column 1 (`.radio-episodes`) stacks the featured image above the episode list, and columns 2–3 (`.radio-featured`) hold the tracklist. There is no visible “Episodes” heading (the section is labelled for screen readers only) and no index numbers on rows. Each episode row is two lines — `.text-fine` on desktop, `.text-body` on mobile — with the title, a 20%-opacity grey slash, and the grey runtime on line one, then Play in grey crossfading to Pause in red on line two, and that Pause is the only red on the row. Both the episode list and the tracklist scroll with hidden scrollbars. The tracklist bar is a 4px-padded white bar with black text on desktop, where it is always open; on mobile it is a black bar with white text (black in every state, open or closed) docked flush above the audio player that expands upward over the page. No in-flow footer; the player is a fixed bottom bar. Audio URLs come from `resolveMixcloudStreamUrl`; Vimeo progressive/HLS URLs from `resolveVimeoStreamUrl` (`VIMEO_ACCESS_TOKEN`). Dark surfaces use `data-work-surface` so rubber-band overscroll stays black.
- All main surfaces share `SiteBrandStrip` for the top band (Daniel Derro in column 1 is the only Home link; desktop nav is Work/Gallery/Info/Radio on the right edge of column 4; a top-right word trigger on mobile opens a heading-size accordion and pushes content). Home and info may enable `blendOverlay` exclusion blend on the brand for media/video legibility. Client breakpoints use `useMediaQuery` in `src/lib/use-media-query.ts`.
- Site typography tokens in `globals.css` (Helvetica Neue via `--font-sans`): `.text-caption` / `.text-caption-tight` (10px), `.text-fine` (12px/16px), `.text-small` (13px/16px), `.text-body` (16px/20px, letter-spacing -0.005em so it reads with the caption's spacing), `.text-heading` (30px/600 with a 28px line-height, overridden taller by `.text-heading.work-heading-line` so descenders are not clipped under `overflow: hidden`), `.text-semantic-title` (16px/500 with trailing comma via `::after`). `.text-small` is the shared style for the brand wordmark, header nav, work captions/filters, and the home hero statement, so changing it moves all of them.
- Shared About/Clients copy, hero logo assets, and radio episode data (`RADIO_INTRO`, `RADIO_EPISODES`) are centralized in `src/lib/site-content.ts`; `INFO_ABOUT` is the full five-paragraph production bio (lead, campaigns/Giveon/Nike/Adidas, editorial and exhibitions, services, community practice) and `/info` renders every entry — do not trim paragraphs when editing that surface; Mixcloud helpers live in `src/lib/mixcloud.ts` / `mixcloud-stream.ts`; No School Vimeo catalog in `src/lib/no-school-videos.ts`; `SnugFillImage` width-fills parent columns without cropping (`src/components/SnugFillImage.tsx`).
- The 2u4u.studio credit comment is rendered by the root layout (`src/app/layout.tsx`) as the first child of `<body>`, inside a `hidden` div via `dangerouslySetInnerHTML` (React cannot emit comment nodes directly). There is no `src/middleware.ts` — an earlier version self-fetched `request.nextUrl` to rewrite the HTML and crashed Vercel with `MIDDLEWARE_INVOCATION_FAILED`. Never re-add middleware that fetches the deployment's own origin. Browser tab titles come from `rootSiteMetadata`/`sitePageTitle` in `src/lib/site-metadata.ts`: mixed-case `Daniel Derro` joined to each page name by a chevron/play-triangle mark (`▸` in `<title>`, matching the SVG chevron used in the UI) — never a dash separator and never all caps.
