## Learned User Preferences

- Keep the interface free of shadows. Motion should feel slow, smooth, and heavy—long easing curves and opacity/filter interpolation only. No bounce, springy overshoot, scale-in, or slide-in entrances. Prefer a minimal site scrollbar (thin, low-contrast light thumb on the black canvas).
- Keep page canvases flat and black site-wide (`html`/`body` use `--color-black`). Avoid extra panel/cell fills unless placeholder media explicitly keeps its fill.
- `SiteBrandStrip` is the fixed transparent top band on home, info, work, radio, and project pages: Daniel Derro links home (left, `.text-small`). Navigation splits by breakpoint. Desktop (≥768px) uses a traditional inline nav (`SiteNavLinks`) on the page `.layout-grid` — Home/Info/Work/Radio side by side with a 12px gap, sitting in the fourth content column (track 4 on the 4-col grid, track 8 on the 8-col grid) aligned to that column’s right edge (not the 300px compact measure). Mobile (<768px) hides that nav and uses a text-only `MobileMenuTrigger` pinned to the top-right: the current page name, fading to Menu when open — no plus/minus, no 140px panel, no frost, no backdrop blur. Opening it drops an accordion of `.text-heading` links that pushes page content down (`--site-mobile-nav-shift`) instead of overlaying it. The header bar is `.layout-grid` (`site-brand-strip-bar`). Brand name links fade to 40% opacity on hover. Do not put Venice/Nineteen Eighty Six in the header. On home, info, and project detail, `SiteChrome` may pass `blendOverlay` so the brand uses exclusion blend (`blend-overlay`) for legibility over media.
- Site-wide page navigation lives in the brand strip only (desktop inline nav, mobile accordion — both from `MobileMenuOverlay.tsx`); there is no fixed bottom nav row. `SitePageFooter` is the shared in-flow footer on info and work (home is a locked hero with no in-flow footer; radio has none); `SiteFooter` renders only on project detail pages (title, tags, slide counter) pinned to the viewport bottom with transparent background and enough scroll padding to clear it. Do not show a phone number in the footer; contact on `/info` is email only (`info@ns-sr.org`).
- For local checks, run the dev server on port 3000 via `npm run dev` (routes through `scripts/dev.sh`, which kills stale listeners then launches Turbopack with `--disable-source-maps`). The repo lives on iCloud Desktop; file-provider I/O can stall Next boot and first-page compile until the folder is downloaded locally. Use `npm run dev:clean` to wipe `.next` first when manifest/cache errors appear. If localhost does not match expected UI, confirm the checked-out branch — home hero/footer redesign lives on `feature/home-hero-updates`, not necessarily `main`.
- UI stack is Next.js with Tailwind and Framer Motion for animation; Sanity CMS at `/studio` is used for client-managed portfolio content. Motion tokens live in `src/lib/motion.ts`; the `.hover-smooth` utility class in `globals.css` handles CSS-driven hover transitions. Scrolling is native except on project pages (`.project-scroll` snap).
- Keep all site typography editable in one `globals.css` Typography block — `.text-caption`, `.text-caption-tight`, `.text-small`, `.text-body`, `.text-heading`, and `.text-semantic-title` ordered smallest→largest with explicit font values; do not scatter typography rules across components. `.text-semantic-title` matches body scale and appends a trailing comma via `::after`; semantic section titles sit flush (0px gap) above their body copy.
- All public horizontal content must use one of three rules in `globals.css`: `.layout-grid` (full-width media grid: 2 columns below 768px, 4 from 768–1023px, 8 from 1024px), `.content-compact` (fluid to 300px), or `.content-wide` (fluid to 800px, with optional `.content-wide-grid` internal columns). Keep `--spacing-margin` at 12px. Do not introduce unrelated max-widths or alternate column systems.
- Home is a locked full-viewport original video hero (`HomeHero.tsx`, `100dvh`, `overflow: hidden` on html/body) — no project index/list, no gallery, no page-grid overlay, no page scroll, no in-flow footer. The intro video fills the viewport like production (`object-fit: cover`, inset 0 / `100dvh`); looping muted video (`/videos/dd-intro-video.mp4`, poster `daniel-hero-new.jpg`) must not show a native Safari play button or controls (`playsInline`, hide `::-webkit-media-controls`). Over it sits one centered `.text-small` statement (`home-hero-center`) locked to the 300px compact width and vertically centered in the viewport: three period-terminated lines (`No School Studios is a visual practice.` / `Founded and operated by Daniel Derro.` / `Based in Venice.`) where only `No School Studios` and `Daniel Derro` are white and the rest is grey `#808080`. The block uses `mix-blend-mode: exclusion` over the video — apply the blend on the wrapper, not the spans, or it will not render.
- The work page follows the Something Special Studios index pattern. A fixed black header (`work-page-header`) sits under `SiteBrandStrip` and stacks a right-aligned `.text-heading` (standing text `Selected Projects` at 20px on mobile, crossfades to the hovered project title, no character limit) above a `text-small` filter group (right-aligned on mobile); title and filters stay pinned and do not scroll with the index. Gaps from brand → title → filters → first project use `--work-row-gap` (12px). Each project is a tight row: a full-width flush thumbnail strip (no gaps, no borders) with a caption row beneath it — client, title, category, year — as a single `text-small` line on the 4-col measure from 768px (tags right-aligned; when year is empty they sit on the right edge); below 768px only client and title show. Every strip is the same height (`--work-thumb-height`); overflow scrolls horizontally with no visible scrollbar. Thumbnails keep their intrinsic aspect ratio via CSS `aspect-ratio`. Hovering a row for 600ms dims every other row to 0.18 (opacity only, no grey fill, no cursor-following preview); leaving or scrolling cancels the hold or clears immediately. Disable the dim on mobile. Client falls back to “No School Studio” for No School rows, otherwise “Personal”. The filter group is All, A-Z, Stills, Motion, No School: every view except A-Z lists projects newest-uploaded first (Sanity `_createdAt`, with the undated No School Vimeo catalog trailing in feed order), and A-Z shows everything sorted alphabetically by title. Black background; `SitePageFooter onDark` at the bottom.
- `SitePageFooter` is a single centered `.text-caption` line in the 300px `.content-compact` rule: `© 2026 NO SCHOOL STUDIOS. ALL RIGHTS RESERVED.` in `#808080`. No links or logos. The gap above it matches `--work-row-gap` (12px); no extra padding below. Page shells are `min-height: 100dvh` flex columns so the footer `margin-top: auto` pins it to the bottom of the viewport when content is short, and to the end of the document when content is long.

## Learned Workspace Facts

- The app uses Next.js 15 (App Router), React 19, and Tailwind CSS v4 with `@tailwindcss/postcss`.
- Layout uses `.layout-grid` (2/4/8 full-width media tracks), `.content-compact` (300px), and `.content-wide` (800px). These are the only public horizontal sizing primitives; `--spacing-margin` is 12px and `--spacing-gutter` is 20px at all breakpoints.
- Earlier microsite code is archived under `src/archive/` rather than mixed into the current site surface. `tsconfig.json` excludes `src/archive` so archived code is not type-checked; `npm run build` can still fail if archived files import packages that are no longer dependencies.
- Global styles strip box shadows site-wide and define a minimal scrollbar outside Sanity Studio. Framer Motion handles animation (page transitions via `src/app/template.tsx`, hover/scroll via motion components). Page transitions skip `/studio` routes. Scrolling is native site-wide; only `/work/[slug]` uses CSS scroll-snap on `.project-scroll`.
- Stale or mixed `.next` output (for example after `next build` then `next dev`) can cause local Internal Server Errors or missing chunk errors; `npm run dev:clean` handles this automatically.
- Never leave large directories (e.g. `node_modules_old`) in the project root — they cause webpack/Turbopack file-watcher exhaustion and hang page compilation indefinitely. `.gitignore` now blocks `node_modules_old`.
- Embedded Sanity CMS powers portfolio projects and media; Studio is at `/studio`. Use versions aligned with Next.js 15 (for example `sanity@4` with `next-sanity@11`). Public contact email shown in the site UI is `info@ns-sr.org`. Server routes use `sanityFetchOrDefault` in `src/sanity/lib/fetch-safe.ts` so failed Sanity fetches fall back to empty data or `notFound` instead of throwing 500s. Project slides use a blurred LQIP/`sanityImageBlurUrl` placeholder while the full image loads.
- Home is a locked 100dvh video-only `HomeHero` (no `--site-content-offset-top` in-flow). Other main surfaces sit `--work-row-gap` (12px) below the fixed brand strip: `/info` uses the same looping hero video as home (`SiteBackgroundVideo` fixed, dimmed to 80%) under the same full-width `.layout-grid` as `/work` (each block `grid-column: span 2`) with `.text-small` copy — grey `#808080` `.text-caption` section titles, white main content, links in `--color-primary` red; `Daniel Derro` white inside the about paragraph; services sit in one Services column; there is no Studio group; clients split into two isles with a 12px gap; row gap is `calc(var(--work-row-gap) * 2)` and label gaps match `--work-row-gap`; `/work` is a black full-width index of flush thumbnail strips with caption rows; `/work/[slug]` uses full-width viewport-snapped media with videos capped by the 800px rule and a fixed 800px `SiteFooter`; `/radio` splits featured left (2 cols: main intro image flush above the latest episode’s tracklist) from a right gallery of square grey-stroke episode cells (index / Play in grey or Pause in red, title, runtime). Tracklist is a white 4px bar with black `.text-small` “Tracklist” text — always open on desktop; on mobile the same bar is a button that expands the list in place (not an overlay or a stretched 44px-tall bar), and the page splits top/bottom so the episode gallery stays visible. No in-flow footer; the player is a fixed bottom bar. Audio URLs come from `resolveMixcloudStreamUrl`; Vimeo progressive/HLS URLs from `resolveVimeoStreamUrl` (`VIMEO_ACCESS_TOKEN`). Dark surfaces use `data-work-surface` so rubber-band overscroll stays black.
- All main surfaces share `SiteBrandStrip` for the top band (Daniel Derro in column 1 + desktop nav on the right edge of column 4, a top-right word trigger on mobile that opens a heading-size accordion and pushes content). Home and info may enable `blendOverlay` exclusion blend on the brand for media/video legibility. Client breakpoints use `useMediaQuery` in `src/lib/use-media-query.ts`.
- Site typography tokens in `globals.css` (Helvetica Neue via `--font-sans`): `.text-caption` / `.text-caption-tight` (10px), `.text-small` (13px), `.text-body` (16px/500), `.text-heading` (48px/600, 56px line-height so descenders are not clipped), `.text-semantic-title` (16px/500 with trailing comma via `::after`). `.text-small` is the shared style for the brand wordmark, header nav, work captions/filters, and the home hero statement, so changing it moves all of them.
- Shared About/Clients copy, hero logo assets, and radio episode data (`RADIO_INTRO`, `RADIO_EPISODES`) are centralized in `src/lib/site-content.ts`; Mixcloud helpers live in `src/lib/mixcloud.ts` / `mixcloud-stream.ts`; No School Vimeo catalog in `src/lib/no-school-videos.ts`; `SnugFillImage` width-fills parent columns without cropping (`src/components/SnugFillImage.tsx`).
- `src/middleware.ts` injects a 2u4u.studio-style HTML credit comment immediately after the opening `<html>` tag on HTML navigations (matcher skips `/studio`, static assets, and API routes). Browser tab titles come from `rootSiteMetadata`/`sitePageTitle` in `src/lib/site-metadata.ts`: mixed-case `Daniel Derro` joined to each page name by a chevron/play-triangle mark (`▸` in `<title>`, matching the SVG chevron used in the UI) — never a dash separator and never all caps.
