## Learned User Preferences

- Keep the interface free of shadows. Motion should feel slow, smooth, and heavy—long easing curves and opacity/filter interpolation only. No bounce, springy overshoot, scale-in, or slide-in entrances.
- Treat the site background as solid white only; avoid extra fill colors on panels or cells unless placeholder media explicitly keeps its fill.
- `SiteBrandStrip` is the fixed transparent top band on home, info, work, radio, and project pages: Daniel Derro links home (left); red Venice/Nineteen Eighty Six meta sits in column 4 from md up and is hidden below md; a Menu trigger (right, near lg column 10) opens `MobileMenuOverlay` — a primary-red dropdown at fixed 320px width (`--site-menu-dropdown-width`) with stacked `text-heading` nav links (Home, Info, Work, Exhibitions, Radio), two-digit accent numbers, and black "– Coming Soon" body text on Exhibitions only. Active nav links default black and invert to white on hover (fast transition); Coming Soon row has no hover. Brand name links fade to 40% opacity on hover. On home and project detail, `SiteChrome` passes `blendOverlay` so the brand/menu trigger use exclusion blend (`blend-overlay` class) for legibility over photos; the dropdown panel stays solid red. On home, blend disables when the hero background has scrolled away (`data-hero-bg-visible`).
- Site-wide page navigation lives in `MobileMenuOverlay` only — there is no fixed bottom nav row. `SitePageFooter` (via `InfoColumns` `siteFooter`) is the shared in-flow footer on home, info, work, and radio; `SiteFooter` renders only on project detail pages (title, tags, slide counter) pinned to the viewport bottom with transparent background and enough scroll padding to clear it.
- For local checks, run the dev server on port 3000 via `npm run dev` (routes through `scripts/dev.sh` which kills stale listeners before launching Turbopack). Use `npm run dev:clean` to wipe `.next` first when manifest/cache errors appear. If localhost does not match expected UI, confirm the checked-out branch — home hero/footer redesign lives on `feature/home-hero-updates`, not necessarily `main`.
- UI stack is Next.js with Tailwind, Framer Motion for animation, and Lenis for smooth scrolling; Sanity CMS at `/studio` is used for client-managed portfolio content. Motion tokens live in `src/lib/motion.ts`; the `.hover-smooth` utility class in `globals.css` handles CSS-driven hover transitions.
- Keep all site typography editable in one `globals.css` Typography block — `.text-micro`, `.text-micro-tight`, `.text-caption`, `.text-body`, `.text-heading`, and `.text-semantic-title` ordered smallest→largest with explicit font values; do not scatter typography rules across components. `.text-semantic-title` is body-scale sans (16px/600) at 20% opacity grey site-wide with `pl-5` indent in footer/info; hero About/Clients labels use a caption-sized white override via `[data-home-hero] .text-semantic-title`. Semantic section titles sit flush (0px gap) above their body copy.
- On small screens, use uniform padding around the layout via `--spacing-margin` (12px at all breakpoints).
- Home hero is `HomeHero.tsx`: full-viewport (`100dvh`) with blurred, grained background fill (`daniel-hero-new.jpg`, `blur-[8px]`, `.hero-grain`); page canvas stays white (no black page-background state). Content stacks in column 2: Daniel Derro + No School Studios in `text-heading` with black label containers (`bg-black px-[2px]`); About/Clients in `text-caption` at 240px width with inline semantic titles; portrait plus four hero-strip logos (Most Wanted and No Cry Baby's hidden in hero only; footer keeps all six `HERO_LOGOS`) at 32px height, 0.5px white stroke, no gap. `gap-5` (20px) between hero blocks. View Gallery is a text button in the footer grid position (col 2) with the same black container styling; visible only when hero is fully in viewport; scroll/click smoothly reaches the gallery while hero content and background fade out. On tablet/mobile, Daniel Derro + No School Studios move into the fixed header position (matching the info page) rather than stacking in the hero column.
- On the home page, present the Sanity-fed gallery as a continuous image grid in page-grid columns 3–8 on lg (six internal tracks) without per-project title rows; show at most 30 images with each row filled; align rows to the top with uniform vertical gap between rows; clicking a gallery image navigates to that image's project. When hovering a gallery image, non-hovered images use about 20% opacity and grayscale.
- On the work page, each project is one generously spaced row starting in column 4 from lg (`--work-row-gap` between rows): numbered index (001…), title/category metadata, and a horizontal thumbnail strip whose visible count shrinks to fit row width; the content columns link to the project. Hover fills only the content area with grey from the top-left; white title inverts to black while muted grey stays grey. Black background; `SitePageFooter onDark` at the bottom. No cursor-following hover preview.
- `SitePageFooter` footer grid is top-aligned with a 20%-opacity black top divider spanning active content columns (`--site-footer-padding` 200px margin above divider and page bottom padding; home `flushTop` keeps gallery-to-footer gap 0). xl placement: logos column 2, Contact column 4, logos column 7 (right-aligned), Follow column 9. Footer logos are inline at 24px height with aspect-ratio widths, 0.5px black stroke, wrapping on new lines within their grid cells. Footer semantic titles use `.text-semantic-title` (grey); body copy black (white on dark work/radio footer). Local static logo images use native `<img>` with `object-contain` to avoid Next.js Image crop/fill. Below 768px footer blocks stack with 80px row-gap; the right logo group left-aligns when stacked.
- Target responsive column counts: two columns below 768px, four columns from 768px to 1023px, ten columns from 1024px up (aligned with `.page-grid` breakpoints); text blocks span two columns on lg via `--grid-span-2-width` / `.lg-col-text`.

## Learned Workspace Facts

- The app uses Next.js 15 (App Router), React 19, and Tailwind CSS v4 with `@tailwindcss/postcss`.
- Layout uses responsive `.page-grid` in `globals.css`: two columns by default, four from `min-width: 768px`, ten from `min-width: 1024px`; `--spacing-margin` is 12px at all breakpoints; `--spacing-gutter` scales by breakpoint. The home gallery uses row spacing tied to `--spacing-gutter` so vertical gaps match horizontal column gutters (avoid a global `.page-grid` `row-gap: 0` rule that overrides intended row gaps).
- Earlier microsite code is archived under `src/archive/` rather than mixed into the current site surface. `tsconfig.json` excludes `src/archive` so archived code is not type-checked; `npm run build` can still fail if archived files import packages that are no longer dependencies.
- Global styles strip box shadows site-wide. Framer Motion handles animation (page transitions via `src/app/template.tsx`, hover/scroll via motion components). Lenis smooth scroll is initialized in `src/components/SmoothScroll.tsx` (lerp 0.07 for heavy feel). Both providers skip `/studio` routes.
- Stale or mixed `.next` output (for example after `next build` then `next dev`) can cause local Internal Server Errors or missing chunk errors; `npm run dev:clean` handles this automatically.
- Never leave large directories (e.g. `node_modules_old`) in the project root — they cause webpack/Turbopack file-watcher exhaustion and hang page compilation indefinitely. `.gitignore` now blocks `node_modules_old`.
- Embedded Sanity CMS powers portfolio projects and media; Studio is at `/studio`. Use versions aligned with Next.js 15 (for example `sanity@4` with `next-sanity@11`). Until video playback exists, gallery `videoAsset` entries should use thumbnails only as on-page stills. Public contact email shown in the site UI is `info@ns-sr.org`. Server routes use `sanityFetchOrDefault` in `src/sanity/lib/fetch-safe.ts` so failed Sanity fetches fall back to empty data or `notFound` instead of throwing 500s.
- Main surfaces use `--site-content-offset-top` (200px) so in-flow content starts on the perceived header line. Beyond home, live routes are `/info` (white background; two hero images side by side with copy below the first image at two-column width — xl locks images to cols 4–5 and 6–7 with page offset; semantic titles flush 0px above body), `/work` (black `WorkProjectGrid` editorial list with `SitePageFooter onDark`), `/work/[slug]` (vertical scroll with viewport-snapped 100dvh slides, 200px top/bottom image padding, fixed `SiteFooter`; no slideshow cursor), and `/radio` (black Identity Correction Radio via `RadioPageClient`: intro title + micro description cols 1–2, episode library cols 3–8 styled like work rows, tracklist box cols 9–10 with dimmed borders matching the active episode; nothing selected on load; clicking an episode shows the tracklist and a fixed full-width bottom `RadioPlayer` — no cover image). `RadioPlayer` (`src/components/RadioPlayer.tsx`) is an HTML5 `<audio>` player showing only play/pause, seek bar, time, and volume with equal 20px gaps, middle-aligned, no container fill/border/padding; audio URLs come from `resolveMixcloudStreamUrl` (`src/lib/mixcloud-stream.ts`); episodes/intro in `RADIO_INTRO`/`RADIO_EPISODES`. Work and radio use `data-work-surface`; `globals.css` sets `html`/`body` black when that marker is present so rubber-band overscroll does not flash the default white canvas.
- All main surfaces share `SiteBrandStrip` for the top band (Daniel Derro + Menu). Home enables `blendOverlay` exclusion blend on brand/menu for photo legibility via `data-hero-bg-visible`. Client breakpoints use `useMediaQuery` in `src/lib/use-media-query.ts`. Project detail desktop split footer layout uses `MEDIA_DESKTOP_FINE_POINTER` in `src/lib/media-queries.ts` (`(min-width: 1024px) and (pointer: fine)`) so wide viewports with touch keep touch-first layout.
- Site typography tokens in `globals.css` (Helvetica Neue via `--font-sans`): `.text-micro` (8px), `.text-micro-tight` (8px tighter lh), `.text-caption` (11px), `.text-body` (16px/600), `.text-heading` (60px/600 for menu nav links), `.text-semantic-title` (16px/600 grey at 20% opacity; caption-sized white in home hero).
- Shared About/Clients copy, hero logo assets, and radio episode data (`RADIO_INTRO`, `RADIO_EPISODES`) are centralized in `src/lib/site-content.ts`; Mixcloud helpers live in `src/lib/mixcloud.ts`; `SnugFillImage` width-fills parent columns without cropping (`src/components/SnugFillImage.tsx`).
- `src/middleware.ts` injects a 2u4u.studio-style HTML credit comment immediately after the opening `<html>` tag on HTML navigations (matcher skips `/studio`, static assets, and API routes). Browser tab titles come from `rootSiteMetadata`/`sitePageTitle` in `src/lib/site-metadata.ts`: mixed-case `Daniel Derro` joined to each page name by a chevron/play-triangle mark (`▸` in `<title>`, matching the SVG chevron used in the UI) — never a dash separator and never all caps.
